# AI Statement — see the repository root

The AI statement for this repository is
[`/AI_STATEMENT.md`](../../AI_STATEMENT.md), at the root, where every other
special file in this directory's checklist lives and where GitHub, tooling,
and readers look for it.

A full draft used to live here as well, written separately from the root
document and divergent from it — the exact failure mode a single source
exists to prevent. Resolved 2026-08-26: the root document is the source. The
two shared the same skeleton — fifteen numbered sections plus the change-log
and machine-readable-summary annexes — and the root's sections are the
fuller ones, verified against this repository's tree rather than asserted
(its §7 names each quality control and what it does and does not prove; its
§8 covers licensing and provenance; it alone carries the trademark notice
rule 5 of [`spec/professionalization/index.md`](../professionalization/index.md)
requires). The draft's text remains in this file's git history.
